# Architecture

Tauri 2 desktop app: Rust backend, React with strict TypeScript in the webview, built with Vite. The stack is decided in the [spec](docs/planning/spec.md) (D-20261030-210000-7b4e). Logic lives in Rust and in plain TypeScript modules with tests; React components only render.

## Layout

```
src-tauri/src/
  domain/        Rust domain modules. Plain Rust, no Tauri types, tested with `cargo test`.
  commands.rs    Tauri commands. Thin wrappers around `domain`, each annotated with `#[specta::specta]`.
  lib.rs         App setup: registers commands with tauri-specta, exports the bindings.
src/
  bindings.ts    Generated by tauri-specta. Do not edit. The only way the frontend calls Rust.
  lib/           TypeScript logic modules. No React, tested with Vitest (`*.test.ts` next to the module).
  stores/        Zustand stores. Hold state, call `lib/` and `bindings.ts`.
  components/    React components. Render only.
    ui/          shadcn/ui components, generated into the repository and owned by it.
  App.tsx        Root component.
```

## Rust to TypeScript

Commands are registered in `lib.rs` with `collect_commands!`. `src/bindings.ts` is regenerated on every debug start of the app and by `cargo test`. The frontend imports `commands` from `@/bindings` and never calls `invoke` directly, so a changed Rust signature becomes a TypeScript compile error in `npm run check`.

## Checks

- `npm run check`: `tsc --noEmit`, Biome (lint and format), Vitest.
- `cd src-tauri && cargo test`: Rust tests, including the bindings export.
- `npm run format`: applies Biome fixes. Markdown, `docs/`, `templates/` and `src-tauri/` are excluded from Biome.

## Dependencies

tauri-specta, specta and specta-typescript have no stable release for Tauri 2 and are pinned to exact release candidates in `src-tauri/Cargo.toml` (D-20261030-211738-9tc3). Everything else uses stable releases.

Tauri plugins: `tauri-plugin-dialog` (folder picker) and `tauri-plugin-store` (app settings in `settings.json` in the app data folder, read and written through `src/stores/settings.ts`). Each plugin gets only the permissions it needs in `src-tauri/capabilities/default.json`.
