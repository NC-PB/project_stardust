## Description
`S-board-sort` is ticked in the [spec](../spec.md) but not built: columns list tasks by file name, and a moved card goes to the end of its column (D-20261030-232042-h9dm). The [session panel](../done/20261031-005408-gv2i-session-panel.md) uses its own interim order until this exists (D-20261031-011606-s3pn); switching it over is [its own task](20261031-012418-sf2u-session-panel-uses-the-board-sort.md).

Open points to decide and record: how priority, created and dependency order combine (for example a task never above a task it depends on in the same column), what happens with dependency cycles or unknown ids, and where a card lands after a move.

## Acceptance criteria
- [ ] Every column orders its cards by priority (1 first, none last), then created, then id, with dependency order applied on top
- [ ] The order is a pure TypeScript function with tests, used by the board
- [ ] A moved card takes its sorted place instead of the end of the column
- [ ] Cycles and unknown dependencies do not break the order
