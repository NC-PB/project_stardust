## Description
Implements `S-fog-meter` in the [spec](../spec.md).

## Acceptance criteria
- [x] Shows ticked versus unticked nodes and answered versus open questions
- [x] Nodes tagged `#later` are counted separately
- [x] Clicking a count lists the nodes or questions behind it

## Implementation notes
- Done: `src/lib/fog.ts` (+ tests) sorts the spec model into the counts and keeps the entries behind each one; `src/components/fog-meter.tsx` renders them from `useSpecStore`; clicking an entry calls `onOpen(at)`.
- Mounted in the spec view by the main session, with `onOpen` opening the editor at the line.

## Result
The fog meter in the spec view shows five counts from the spec model: ticked, unticked and `#later` nodes, answered and open questions. Domain areas are not counted. Clicking a count lists the nodes or questions behind it, and clicking one of those opens the spec at its line.
- Not tried by hand in the running app.
