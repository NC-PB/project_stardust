## Result
The session panel sits under the search box whenever a project is open: the tasks ready in the ready column (priority 1 to 5 first, then by file name), the last finished task with its Result, the last five decisions (newest first, superseded ones struck through) and the open blocking questions. Everything is computed from the board and spec stores and follows watcher batches. Each entry opens its file in the editor, spec entries at their line. "Hide" hides the panel for the open project for this session; nothing is written.
- Not tried by hand in the running app.
- Only tasks directly in the terminal column count for "last finished"; the archive `done/YYYY-MM/` is not read.
